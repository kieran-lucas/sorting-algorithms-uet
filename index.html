1. Merge Sort

Java · Programiz

Merge Sort là thuật toán sắp xếp dựa trên nguyên lý chia để trị (Divide and Conquer). Thay vì sắp xếp trực tiếp toàn bộ mảng, thuật toán liên tục chia mảng thành hai nửa có kích thước gần bằng nhau, cho đến khi mỗi phần chỉ còn một phần tử. Trong chương trình, quá trình này được thực hiện bằng hàm đệ quy mergeSort(), với m là vị trí chia mảng thành hai nửa.

Sau khi chia, thuật toán tiến hành gộp các phần đã có thứ tự thông qua hàm merge(). Hai nửa được sao chép vào các mảng tạm L và M, sau đó lần lượt so sánh các phần tử tương ứng để chọn giá trị nhỏ hơn đưa trở lại mảng ban đầu arr. Khi một trong hai mảng tạm đã hết phần tử, các phần tử còn lại của mảng kia được đưa vào những vị trí tiếp theo. Nhờ đó, mỗi lần gộp tạo ra một đoạn có thứ tự lớn hơn, cho đến khi toàn bộ mảng được sắp xếp hoàn chỉnh.

Code

// Merge sort in Java

class MergeSort {

  // Merge two subarrays L and M into arr
  void merge(int arr[], int p, int q, int r) {

    int n1 = q - p + 1;
    int n2 = r - q;

    int L[] = new int[n1];
    int M[] = new int[n2];

    for (int i = 0; i < n1; i++)
      L[i] = arr[p + i];
    for (int j = 0; j < n2; j++)
      M[j] = arr[q + 1 + j];
    // Maintain current index of sub-arrays and main array
    int i, j, k;
    i = 0;
    j = 0;
    k = p;

    // Until we reach either end of either L or M, pick smaller among
    // elements L and M and place them in the correct position at A[p..r]
    while (i < n1 && j < n2) {
      if (L[i] <= M[j]) {
        arr[k] = L[i];
        i++;
      } else {
        arr[k] = M[j];
        j++;
      }
      k++;
      System.out.printf("merge(%d,%d,%d), k=%d: ", p, q, r, k - 1);
      printArray(arr);
    }
    // When we run out of elements in either L or M,
    // pick up the remaining elements and put in A[p..r]
    while (i < n1) {
      arr[k] = L[i];
      i++;
      k++;
      System.out.printf("merge(%d,%d,%d), k=%d: ", p, q, r, k - 1);
      printArray(arr);
    }

    while (j < n2) {
      arr[k] = M[j];
      j++;
      k++;
      System.out.printf("merge(%d,%d,%d), k=%d: ", p, q, r, k - 1);
      printArray(arr);
    }
  }

  // Divide the array into two subarrays, sort them and merge them
  void mergeSort(int arr[], int l, int r) {
    if (l < r) {
      // m is the point where the array is divided into two subarrays
      int m = (l + r) / 2;

      mergeSort(arr, l, m);
      mergeSort(arr, m + 1, r);

      // Merge the sorted subarrays
      merge(arr, l, m, r);
    }
  }

  // Print the array
  static void printArray(int arr[]) {
    int n = arr.length;
    for (int i = 0; i < n; ++i)
      System.out.print(arr[i] + " ");
    System.out.println();
  }
  // Driver program
  public static void main(String args[]) {
    int arr[] = { 6, 5, 12, 10, 9, 1 };

    MergeSort ob = new MergeSort();
    System.out.print("Input: ");
    printArray(arr);
    ob.mergeSort(arr, 0, arr.length - 1);

    System.out.println("Sorted array:");
    printArray(arr);
  }
}

2. Counting Sort

Java · Programiz

Counting Sort sắp xếp các số nguyên không âm bằng cách đếm số lần xuất hiện của từng giá trị, thay vì trực tiếp so sánh các phần tử với nhau. Trong chương trình, hàm countSort() trước hết tìm giá trị lớn nhất max để tạo mảng đếm count có đủ vị trí cho các giá trị từ 0 đến max. Sau đó, mỗi phần tử array[i] làm tăng ô count[array[i]], giúp xác định chính xác số lần xuất hiện của từng giá trị.

Từ mảng đếm, thuật toán tính tổng tích lũy bằng cách cộng số đếm hiện tại với các giá trị đứng trước. Khi đó, count[x] cho biết có bao nhiêu phần tử nhỏ hơn hoặc bằng x, qua đó xác định vị trí của từng phần tử trong mảng kết quả output. Chương trình duyệt mảng gốc từ phải sang trái, đặt phần tử vào vị trí count[array[i]] - 1 rồi giảm số đếm tương ứng, nhờ vậy giữ được thứ tự tương đối của các phần tử bằng nhau. Cuối cùng, mảng output được sao chép trở lại array.

Code

// Counting sort in Java programming (Programiz), with trace output
import java.util.Arrays;

class CountingSort {
  void countSort(int array[], int size) {
    if (size == 0) return;
    int[] output = new int[size];

    // Find the largest element of the array
    int max = array[0];
    for (int i = 1; i < size; i++) {
      if (array[i] > max)
        max = array[i];
    }
    int[] count = new int[max + 1];

    System.out.println("COUNT START | C=" + Arrays.toString(count));
    // Store the count of each element
    for (int i = 0; i < size; i++) {
      count[array[i]]++;
      System.out.printf("COUNT i=%d | C=%s%n", i, Arrays.toString(count));
    }

    // Store the cumulative count of each array
    for (int i = 1; i <= max; i++) {
      count[i] += count[i - 1];
      System.out.printf("PREFIX i=%d | C=%s%n", i, Arrays.toString(count));
    }

    System.out.println("PLACE START | B=" + Arrays.toString(output));
    // Place elements in output array
    for (int i = size - 1; i >= 0; i--) {
      int position = count[array[i]] - 1;
      output[position] = array[i];
      count[array[i]]--;
      System.out.printf("PLACE i=%d pos=%d | B=%s | C=%s%n",
          i, position, Arrays.toString(output), Arrays.toString(count));
    }

    // Copy the sorted elements into original array
    for (int i = 0; i < size; i++) {
      array[i] = output[i];
      System.out.printf("COPY i=%d | A=%s%n", i, Arrays.toString(array));
    }
  }

  public static void main(String args[]) {
    int[] data = {4, 2, 2, 8, 3, 3, 1};
    int size = data.length;
    System.out.println("INPUT | A=" + Arrays.toString(data));
    CountingSort cs = new CountingSort();
    cs.countSort(data, size);
    System.out.println("RESULT | A=" + Arrays.toString(data));
  }
}

3. Bucket Sort

Java · Programiz

Bucket Sort tổ chức việc sắp xếp bằng cách phân phối các phần tử vào nhiều nhóm (bucket) theo khoảng giá trị, sau đó xử lý từng nhóm riêng biệt. Với dữ liệu trong chương trình gồm các số thực thuộc khoảng [0, 1), hàm bucketSort() tạo n bucket và xác định nhóm của mỗi phần tử bằng bucketIndex = (int) (arr[i] * n). Nhờ cách chia này, những giá trị nhỏ được đưa vào các bucket có chỉ số thấp, còn những giá trị lớn nằm ở các bucket có chỉ số cao hơn.

Sau khi phân phối hết các phần tử, chương trình sử dụng Collections.sort() để sắp xếp các giá trị bên trong từng bucket theo thứ tự tăng dần. Thuật toán không cần so sánh phần tử giữa các bucket vì các khoảng giá trị đã được chia theo đúng thứ tự. Cuối cùng, chương trình duyệt các bucket từ chỉ số nhỏ đến lớn, lần lượt lấy các phần tử đã sắp xếp và ghi trở lại mảng arr. Khi ghép hết các nhóm, toàn bộ mảng được sắp xếp hoàn chỉnh.

Code

// Bucket sort in Java (Programiz), with trace output
import java.util.ArrayList;
import java.util.Collections;
import java.util.Arrays;

public class BucketSort {
  public void bucketSort(float[] arr, int n) {
    if (n <= 0)
      return;
    @SuppressWarnings("unchecked")
    ArrayList<Float>[] bucket = new ArrayList[n];

    // Create empty buckets
    for (int i = 0; i < n; i++)
      bucket[i] = new ArrayList<Float>();

    // Add elements into the buckets
    for (int i = 0; i < n; i++) {
      int bucketIndex = (int) (arr[i] * n);
      bucket[bucketIndex].add(arr[i]);
      System.out.printf("DISTRIBUTE i=%d bucket=%d | B%d=%s%n",
          i, bucketIndex, bucketIndex, bucket[bucketIndex]);
    }

    // Sort the elements of each bucket
    for (int i = 0; i < n; i++) {
      Collections.sort((bucket[i]));
      System.out.printf("SORT bucket=%d | B%d=%s%n", i, i, bucket[i]);
    }

    // Get the sorted array
    int index = 0;
    for (int i = 0; i < n; i++) {
      for (int j = 0, size = bucket[i].size(); j < size; j++) {
        int position = index;
        arr[index++] = bucket[i].get(j);
        System.out.printf("GATHER bucket=%d index=%d | A=%s%n",
            i, position, Arrays.toString(arr));
      }
    }
  }

  public static void main(String[] args) {
    BucketSort b = new BucketSort();
    float[] arr = {(float) 0.42, (float) 0.32, (float) 0.33,
        (float) 0.52, (float) 0.37, (float) 0.47, (float) 0.51};
    System.out.println("INPUT | A=" + Arrays.toString(arr));
    b.bucketSort(arr, 7);
    System.out.println("RESULT | A=" + Arrays.toString(arr));
  }
}

4. Radix Sort

Java · Programiz

Radix Sort sắp xếp các số nguyên không âm theo từng chữ số, bắt đầu từ hàng đơn vị rồi chuyển dần sang hàng chục, hàng trăm và các hàng cao hơn. Trong chương trình, hàm radixSort() dùng getMax() để xác định số lượt cần thực hiện; biến place lần lượt nhận các giá trị 1, 10, 100, ... Ở mỗi lượt, thuật toán chỉ xét chữ số tại hàng đang xử lý, được lấy bằng biểu thức (array[i] / place) % 10.

Để sắp xếp theo chữ số đó, chương trình gọi countingSort() với mảng đếm count[10] ứng với mười chữ số từ 0 đến 9. Sau bước đếm và cộng dồn, các phần tử được đưa vào mảng tạm output theo thứ tự của chữ số hiện tại; việc duyệt từ phải sang trái giúp giữ nguyên thứ tự tương đối của những phần tử có cùng chữ số. Tính ổn định này bảo toàn kết quả sắp xếp ở các hàng thấp hơn, nên sau khi xử lý đến hàng cao nhất, toàn bộ mảng có thứ tự tăng dần.

Code

// Radix Sort in Java Programming (Programiz), with trace output
import java.util.Arrays;

public class RadixSort {
  // Using counting sort to sort the elements based on significant places
  public static void countingSort(int[] array, int place) {
    int size = array.length;
    int[] output = new int[size];
    int[] count = new int[10];

    // Calculate count of elements
    for (int i = 0; i < size; i++) {
      int index = (array[i] / place) % 10;
      count[index]++;
      System.out.printf("COUNT place=%d i=%d | C=%s%n", place, i, Arrays.toString(count));
    }
    // Calculate cumulative count
    for (int i = 1; i < 10; i++) {
      count[i] += count[i - 1];
      System.out.printf("PREFIX place=%d i=%d | C=%s%n", place, i, Arrays.toString(count));
    }
    // Place the elements in sorted order
    for (int i = size - 1; i >= 0; i--) {
      int index = (array[i] / place) % 10;
      int position = count[index] - 1;
      output[position] = array[i];
      count[index]--;
      System.out.printf("PLACE place=%d i=%d pos=%d | B=%s | C=%s%n",
          place, i, position, Arrays.toString(output), Arrays.toString(count));
    }
    // Copy the sorted elements into original array
    for (int i = 0; i < size; i++) {
      array[i] = output[i];
      System.out.printf("COPY place=%d i=%d | A=%s%n", place, i, Arrays.toString(array));
    }
  }
  // Main function to implement radix sort
  public static void radixSort(int[] array) {
    if (array.length == 0) return;
    // Get maximum element
    int maxElement = getMax(array);
    // Apply counting sort to sort elements based on place value
    for (int place = 1; maxElement / place > 0; ) {
      countingSort(array, place);
      if (place > maxElement / 10) break;
      place *= 10;
    }
  }
  // A utility function to get the maximum value in the array
  public static int getMax(int[] array) {
    int max = array[0];
    for (int i = 1; i < array.length; i++) {
      if (array[i] > max) {
        max = array[i];
      }
    }
    return max;
  }
  public static void main(String[] args) {
    int[] data = {121, 432, 564, 23, 1, 45, 788};
    System.out.println("INPUT | A=" + Arrays.toString(data));
    radixSort(data);
    System.out.println("RESULT | A=" + Arrays.toString(data));
  }
}

5. Natural Merge Sort

Java · HappyCoders

Natural Merge Sort là một biến thể của Merge Sort tận dụng những đoạn đã có thứ tự sẵn trong mảng, thay vì luôn chia mảng thành hai nửa theo vị trí. Trong chương trình, hàm sort() duyệt mảng elements để phát hiện các đoạn không giảm liên tiếp, gọi là run. Khi phần tử hiện tại nhỏ hơn phần tử trước đó, một run kết thúc; các vị trí ranh giới được lưu trong mảng starts. Nhờ vậy, thuật toán có thể tận dụng ngay những phần dữ liệu đã được sắp xếp từ trước.

Sau khi xác định các run, thuật toán lần lượt gộp từng cặp run kề nhau bằng hàm merge(), tạo thành những run dài hơn và vẫn có thứ tự. Hai mảng from và to lần lượt giữ vai trò nguồn và đích của mỗi lượt gộp; nếu số run là lẻ, run cuối được sao chép sang mảng đích mà không cần gộp. Sau mỗi lượt, hai mảng đổi vai trò và số run giảm dần. Quá trình kết thúc khi chỉ còn một run bao phủ toàn bộ mảng, chính là dãy đã sắp xếp.

Code

// Natural Merge Sort based on HappyCoders (Sven Woltmann), with trace output
import java.util.Arrays;

public class NaturalMergeSort {
  public void sort(int[] elements) {
    int numElements = elements.length;
    int[] tmp = new int[numElements];
    int[] starts = new int[numElements + 1];

    // Step 1: identify runs
    int runCount = 0;
    starts[0] = 0;
    for (int i = 1; i <= numElements; i++) {
      if (i == numElements || elements[i] < elements[i - 1]) {
        starts[++runCount] = i;
        System.out.printf("RUN start=%d end=%d | R=%s%n",
            starts[runCount - 1], i - 1,
            Arrays.toString(Arrays.copyOfRange(elements, starts[runCount - 1], i)));
      }
    }

    // Step 2: merge runs, until only 1 run is left
    int[] from = elements;
    int[] to = tmp;
    int pass = 1;
    while (runCount > 1) {
      int newRunCount = 0;

      // Merge two runs each
      for (int i = 0; i < runCount - 1; i += 2) {
        merge(from, to, starts[i], starts[i + 1], starts[i + 2]);
        System.out.printf("MERGE pass=%d left=%d mid=%d end=%d | T=%s%n",
            pass, starts[i], starts[i + 1], starts[i + 2], Arrays.toString(to));
        starts[newRunCount++] = starts[i];
      }

      // Odd number of runs? Copy the last one
      if (runCount % 2 == 1) {
        int lastStart = starts[runCount - 1];
        System.arraycopy(from, lastStart, to, lastStart, numElements - lastStart);
        System.out.printf("REMAIN pass=%d start=%d | T=%s%n",
            pass, lastStart, Arrays.toString(to));
        starts[newRunCount++] = lastStart;
      }

      starts[newRunCount] = numElements;
      runCount = newRunCount;

      int[] help = from;
      from = to;
      to = help;
      System.out.printf("PASS pass=%d | A=%s%n", pass, Arrays.toString(from));
      pass++;
    }

    // If final run is not in "elements", copy it there
    if (from != elements) {
      System.arraycopy(from, 0, elements, 0, numElements);
      System.out.println("FINAL COPY | A=" + Arrays.toString(elements));
    }
  }

  // Merge the runs [left, middle) and [middle, right) into target
  private void merge(int[] source, int[] target, int left, int middle, int right) {
    int i = left;
    int j = middle;
    for (int k = left; k < right; k++) {
      if (i >= middle) {
        target[k] = source[j++];
      } else if (j >= right) {
        target[k] = source[i++];
      } else if (source[i] <= source[j]) {
        target[k] = source[i++];
      } else {
        target[k] = source[j++];
      }
    }
  }

  public static void main(String[] args) {
    int[] data = {1, 5, 10, 16, 3, 4, 23, 9, 13, 2, 7, 8, 12, 14};
    System.out.println("INPUT | A=" + Arrays.toString(data));
    new NaturalMergeSort().sort(data);
    System.out.println("RESULT | A=" + Arrays.toString(data));
  }
}

6. Shell Sort

Java · Programiz

Shell Sort là một cải tiến của Insertion Sort, nhằm giảm số lần dịch chuyển phần tử khi những giá trị cần đổi vị trí nằm cách xa nhau. Thay vì sắp xếp ngay các phần tử liền kề, thuật toán sử dụng khoảng cách interval, bắt đầu bằng một nửa độ dài mảng n / 2 và liên tục giảm một nửa sau mỗi lượt cho đến khi bằng 1. Các phần tử cách nhau interval vị trí được sắp xếp trước, giúp những giá trị ở xa dần tiến gần đến vị trí thích hợp.

Với mỗi khoảng cách, chương trình thực hiện thao tác chèn trên các dãy phần tử tương ứng. Giá trị đang xét được tạm giữ trong temp, còn những phần tử đứng trước cách nhau interval vị trí sẽ được dịch sang phải nếu lớn hơn temp. Khi tìm được vị trí phù hợp, temp được chèn trở lại mảng. Khi interval = 1, thuật toán thực hiện Insertion Sort thông thường trên toàn bộ mảng; nhờ các lượt sắp xếp với khoảng cách lớn trước đó, mảng thường đã gần có thứ tự nên cần ít thao tác dịch chuyển hơn.

Code

// Shell sort in Java programming (Programiz), with trace output
import java.util.Arrays;

// Shell sort
class ShellSort {

  // Rearrange elements at each n/2, n/4, n/8, ... intervals
  void shellSort(int array[], int n) {
    for (int interval = n / 2; interval > 0; interval /= 2) {
      System.out.printf("GAP START gap=%d | A=%s%n", interval, Arrays.toString(array));
      for (int i = interval; i < n; i += 1) {
        int temp = array[i];
        int j;
        for (j = i; j >= interval && array[j - interval] > temp; j -= interval) {
          array[j] = array[j - interval];
          System.out.printf("SHIFT gap=%d i=%d from=%d to=%d | A=%s%n",
              interval, i, j - interval, j, Arrays.toString(array));
        }
        array[j] = temp;
        System.out.printf("INSERT gap=%d i=%d pos=%d | A=%s%n",
            interval, i, j, Arrays.toString(array));
      }
      System.out.printf("GAP END gap=%d | A=%s%n", interval, Arrays.toString(array));
    }
  }

  // Driver code
  public static void main(String args[]) {
    int[] data = {9, 8, 3, 7, 5, 6, 4, 1};
    int size = data.length;
    System.out.println("INPUT | A=" + Arrays.toString(data));
    ShellSort ss = new ShellSort();
    ss.shellSort(data, size);
    System.out.println("RESULT | A=" + Arrays.toString(data));
  }
}
